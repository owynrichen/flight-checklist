    • Master Switch — OFF
    • All Electrical Switches — OFF

    🔄 IF ELECTRICAL POWER REQUIRED

    • Master — ON
    • Essential Circuits — ON ONE AT A TIME
    • If smoke returns ➡ Master OFF → Land ASAP

    ⚠️ ALTERNATOR FAILURE / NO CHARGE

    ▶ FLOW

    • Radio call — advise ATC / request assistance and vectors
    • Squawk — as assigned; 7600 if radios fail
    • Electrical Load — REDUCE
    • Alternator Field CB — CHECK / RESET
    • Alternator Output CB — CHECK / RESET
    • Alternator — OFF (30 sec) → ON

    ✔ VERIFY

    • Ammeter shows system load
    • If no output ➡ Alternator OFF → Minimal load → Land ASAP / Practical

    IFR ACRONYMS / MNEMONICS

    • IFR - Instrument Flight Rules
    • VFR - Visual Flight Rules
    • CDI - Course Deviation Indicator
    • DME - Distance Measuring Equipment
    • RNAV - Area Navigation
    • ILS - Instrument Landing System
    • FAF - Final Approach Fix
    • MAP - Missed Approach Point
    • MSA - Minimum Safe Altitude
    • DA/MDA - Decision Altitude / Minimum Descent Altitude
    • WAAS - Wide Area Augmentation System
    • RAIM - Receiver Autonomous Integrity Monitoring
    • ETE - Estimated Time Enroute
    • ETA - Estimated Time of Arrival
    • QNH - Altimeter setting to sea level
    • DADS - Distance, Altitude, Direction, Speed. Check every 1 NM or 500
    • FT.
    • 6 Ts - Turn, Time, Twist, Throttle, Talk, Track.
    • GUMPF - Gas, Undercarriage, Mixture, Propeller, Flaps.
    • GUMPS - Gas, Undercarriage, Mixture, Propeller, Seatbelts.
    • CRAFT - Clearance, Route, Altitude, Frequency, Transponder.
    • PAVE - Pilot, Aircraft, enVironment, External pressures.
    • IMSAFE - Illness, Medication, Stress, Alcohol, Fatigue, Emotion.
    • ARROW - Airworthiness certificate, Registration, Radio license,
    • Operating handbook, Weight and balance.
    • ATOMATOFLAMES - Common required instruments and equipment.
    • 3 Ps - Perceive, Process, Perform.
    • 5 Ps - Plane, Pilot, Passengers, Programming, Plan.
